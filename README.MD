# Dynamic Gears (WIP)
An Autodesk Fusion Add-in that adds multiple options to insert gears into either Part, Assembly, or Hybrid designs.

## Features
- Supports spur, helical, double helical, internal, bevel gear shapes
- Provides a custom Fusion feature that can be parametrically modified in the timeline
- Provides a profile sketch to easily extend the gear part
- Insert gear either as a body or a component(within Assembly and Hybrid designs)
